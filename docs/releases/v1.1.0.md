# Blipzo Web v1.1.0 Release Notes

## Overview
- **Version:** v1.1.0
- **Release Date:** 2026-02-02
- **Summary:** v1.1.0 updates the web app to the `/api/v1.1` backend, adds multi-step auth flows (OTP registration, password reset, and email change), and introduces currency preferences. It also delivers a noticeably smoother UI/UX with refined landing visuals, new modal/overlay patterns, improved transaction browsing (filters, summaries, mobile cards), and more consistent feedback states across the app.

## Features
- **Multi-step authentication UI**
  - OTP-based registration flow with resend countdown and inline OTP input.
  - Dedicated forgot/reset password routes with token-aware flows.
  - Secure change email and change password flows in Settings.
- **Currency preferences**
  - Currency selector in Profile and a dedicated Currency settings tab.
- **Expanded settings experience**
  - Tabbed Settings modal with Profile, Categories, Currency, and Security sections.
  - Overlay-driven flows for sensitive actions (email/password updates).
- **Transaction experience upgrades**
  - New summary modal with styled balance breakdown and date-range context.
  - Enhanced transaction browsing with filters, grouping, and refined sorting controls.
  - Mobile-friendly transaction cards and a compact Today summary card.
- **Landing page polish**
  - Improved layout density, responsive preview placement, and background glow treatments.
 - **Mobile responsiveness upgrades**
   - Dedicated mobile summary card and improved Today view layout.
   - Responsive transaction list with card-based presentation on small screens.
   - Settings modal includes a bottom tab bar for easy thumb navigation on mobile.

## Bug Fixes
- Improved session refresh handling and normalized error reporting for v1.1 response envelopes.
- Reduced double-submit risk across auth flows with blocking states and confirmation prompts.

## Improvements / Refactors
- **API client upgrade**: versioned endpoint prefix (`VITE_API_VERSION`), standardized error normalization, and response unwrapping for v1.1.
- **New UI primitives**: blocking/confirmation modals, OTP input, inline toasts, scroll-locking overlays, and reusable security panels.
- **Dashboard UX refinement**: custom filter dropdowns with search, date presets, and improved grouping/sorting UX.
- **Responsive layout improvements**: mobile-first spacing tweaks, preview placement shifts, and better modal behavior on small screens.
- **Layout cleanup**: App navbar moved to layouts and dashboard components reorganized for clearer structure.
- **Deployment tooling**: Dockerfile, Nginx SPA routing config, GitLab CI, and robots.txt.

## Known Limitations
- Requires Blipzo API v1.1+ with cookie-based auth and CORS credentials enabled.
- Offline mode is not supported.

## Setup / Run Instructions (high-level)
- See `v1.0.0.md` for full setup instructions.
- Optional: set `VITE_API_VERSION=v1.1` (defaults to v1.1 if unset).

## Branching & Versioning Strategy
- **main**: Production
- **dev**: Staging
- **feature/*** : Features

## Notes
- Password reset and email change flows depend on backend email delivery being configured.
- If you previously hardcoded `/api/v1`, ensure your backend supports `/api/v1.1` or set `VITE_API_VERSION` accordingly.
